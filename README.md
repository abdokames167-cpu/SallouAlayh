# صلّوا عليّ ﷺ — Android

النسخة الأولية الرسمية للمشروع.

## ما تم تجهيزه
- اسم التطبيق: صلّوا عليّ ﷺ
- الأيقونة الإسلامية الأخضر/الذهبي المرفقة من التصميم النهائي.
- واجهة عربية RTL.
- عداد الصلاة على النبي.
- أقسام الأذكار الأساسية.
- صلاحية الإشعارات.
- صلاحية الظهور فوق التطبيقات لتجهيز الذكر العابر.
- بنية قابلة للتوسعة.

## الإصدار التالي
- نصوص الأذكار كاملة مع مصادرها.
- شاشة مستقلة لكل قسم وعداد لكل ذكر.
- الذكر العابر: عدد مرات يومية يحددها المستخدم + أوقات بداية/نهاية + تغيير الذكر كل مرة.
- سحب الإشعار وإخفاؤه.
- إحصائيات يومية/أسبوعية/شهرية.
- ويدجت.
- تحسينات توافق Android الحديثة.
